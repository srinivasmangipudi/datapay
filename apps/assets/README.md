# DataPay — Brand Asset Library
Two-tone "circle holds square" mark · Sealed Ledger design system

## The mark
A circle (the collective) holds a square (the individual's sealed data record).
The circle is split: ink (left) = custody/protection, brass (right) = value/pay.
A porcelain data point sits at the centre. It is the deliberate inverse of a
rounded-square-holding-a-circle, so it never reads as a social-media app.

## Palette
- Ink        #101418   text, dark surfaces, "custody"
- Porcelain  #F6F5F1   light surfaces
- Jade       #0E7A5C   trust, growth, the data record (primary accent)
- Jade bright#12946F   jade on dark
- Brass      #B98F2F   value & money ONLY, "pay"
- Brass br.  #D4AA45   brass on dark
- Mist       #8A939B   secondary text

## Type
- Display: Cabinet Grotesk 800 (Fontshare, free)
- Body:    Switzer 400/500 (Fontshare, free)
- Data/UI: Spline Sans Mono (Google Fonts, free)
Wordmark: "Data" upright ink, "Pay" skewed -9deg in brass.

## Usage rules
- Brass is reserved for value/money and the "Pay" wordmark. Never body text.
- Minimum mark clear space = height of the inner square on all sides.
- Favicon uses the simplified (seamless) mark; the split-circle version
  muddies below ~24px.
- Every app-icon TILE is a rounded square by platform rule; the MARK inside
  is a circle, so the logo stays distinct in a phone grid.
